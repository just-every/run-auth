# Verify Auth

Run `pnpm exec rer check --profile first-party`, `node src/base/contract-docs.mjs check`, `pnpm check:sources` and `pnpm verify`. Verify Auth runs the native protocol, workforce, CLI and browser journeys. The contract’s Evidence cells name the sanity journeys that cover each delivered clause. A journey must perform and check its outcomes; no separate assertion per point, mutation, unit or pin test, or test count is required. Money, security and data-loss journeys complete the allowed case and refuse the unsafe case without change. Provider sandboxes and official-schema fakes prove product behavior; real vendor receipts, human accessibility work and elapsed service observations belong to the Field proof register.

Build the public documentation with `pnpm exec rer build --site --non-interactive`. Never treat a provider acknowledgment as an employee receipt or a local fixture as vendor certification. Historical conformance results are in CHANGELOG.md.
